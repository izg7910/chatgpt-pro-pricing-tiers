- Pro 500 是唯一带 Ultrafast 的档位。Ultrafast 是 GPT-6 Astra 的加速推理层，在 Codex 里 token 生成速度最高可到每秒 300 个，官方说法是比标准速度最高快 8 倍。Pro 100 和 Pro 200 就算单独买 credits，也不会解锁这个档位。
- 三档的**核心能力是一样的**：Pro 模型、Codex、deep research、图片生成、记忆、文件上传都包含，差别在用量。Pro 用户还能拿到 1 个 Dots，与 Dots 的对话不计入常规 ChatGPT 配额。

## 第三方渠道的真实风险，别只看价格

这部分公开记录里有不少实例，值得在下单前读完：

- **续费不是必然成功。** 2026 年 8 月有公开记录显示，BeWild 的 ChatGPT Plus 订阅在自动续费节点出现付款失败，原有账单作废，用户按未完成部分拿到退款后重新下单才恢复；也有新购订单显示完成但账号仍是免费版，最终通过退款处理解决。
- **账号归属要看模式。** 直冲模式是在你自己的 ChatGPT 账号上开通，需要上传账号登录状态（Session）让平台自动登录完成续订；代充模式拿到的可能是别人的号。前者账号是你的，后者便宜但账号不属于你。
- **低价 Pro 渠道有过集体掉订阅的情况。** 论坛上有用户反馈，包括 BeWild 在内的多个渠道，Pro 20x 账号在额度刷新后出现订阅掉线，平台提供了修复流程，但并非所有人都一次修复成功；也有用户表示客服最终给了补号或退款。用不用这类渠道，本质是在价格和稳定性之间选一边。
- **客服响应有时间差。** 上面几起案例里，客服恢复回复前的等待时间不算短，着急用的时候要有心理准备。

把这些风险换算成成本，结论挺直接：短期试用买 1 个月，长期使用别一次性堆太多月份，账号出问题时至少损失可控。
